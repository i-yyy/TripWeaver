# 场景描述

适用于个人独自漫游黄山，重点是攀登黄山观赏奇松、怪石、云海、日出，探访宏村、西递等徽派古镇，感受徽派建筑的魅力，游览新安江山水画廊，体验“画里乡村”的诗意。

# 推荐策略

黄山核心是山水与徽派古镇，建议安排3天。第一天前往黄山风景区，登山游览，住山顶准备看日出；第二天看完日出后下山，下午逛屯溪老街，感受徽州烟火气；第三天前往宏村、西递，沉浸式体验徽派古镇，时间充裕可延伸至齐云山或新安江山水画廊。各景点间有旅游大巴联动，交通便捷。

# 可选地点

- 黄山风景区：世界自然与文化双重遗产，奇松怪石云海，建议安排1-2天

- 宏村：徽派古镇典范，“画里乡村”，建议停留2小时

- 西递：徽派古村落，建筑保存完整，建议停留2小时

- 屯溪老街：徽州古街，特色小吃与手工艺品集中，建议停留1.5小时

- 齐云山：道教名山，丹霞地貌，建议安排半天

- 新安江山水画廊：沿江风光秀丽，可乘船游览，建议安排半天

# 约束与风险

- 黄山风景区门票、索道价格较高，建议提前网购套票

- 山顶住宿价格昂贵，需提前预订，冬季部分住宿关闭

- 黄山天气多变，需提前查询天气预报，备好雨具与保暖衣物

- 宏村、西递周末人流量大，建议错峰游览，清晨或傍晚最佳

# 推荐文案

黄山个人漫游建议安排3天，这里是上帝打翻的调色盘，藏着中国最美的山水与徽韵。第一天奔赴黄山风景区，坐索道上山，走在山间步道，看奇松破石而生、怪石形态各异，傍晚等待云海翻涌，住山顶期待第二天的日出。第二天早起看日出染红天际，下山后直奔屯溪老街，吃一碗徽州臭鳜鱼、尝一块黄山烧饼，感受徽州的烟火气。第三天去宏村、西递，走在青石板路上，看白墙黛瓦映着绿水青山，仿佛走进了水墨画里。如果时间充裕，去齐云山感受道教文化，或乘游船游览新安江，每一处都能让你沉醉其中，不愿离去。
