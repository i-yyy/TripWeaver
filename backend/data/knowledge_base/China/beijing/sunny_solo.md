# 城市定位
北京是全国唯一在各大文旅榜单均稳居前三的城市，兼具皇家文化、现代娱乐与地道烟火气，是国内外游客首选目的地。

# 核心亮点
- 皇家古迹：故宫、天坛、颐和园、长城，世界文化遗产密集
- 现代娱乐：北京环球影城，顶流主题乐园体验
- 城市烟火：胡同漫游、前门大栅栏、庙会年味
- 美食名片：北京烤鸭、涮羊肉、炸酱面、卤煮

# 推荐行程
- 1日经典线：天安门广场 → 故宫 → 景山 → 南锣鼓巷
- 1日自然线：八达岭长城 → 奥林匹克公园
- 1日乐园线：北京环球影城全天游玩
- 1日休闲线：颐和园 → 圆明园 → 清华北大外景

# 适合人群
首次来华游客、历史文化爱好者、家庭亲子、春节年味体验

# 出行贴士
- 最佳季节：9–10月秋高气爽；春节庙会氛围浓厚
- 故宫、长城、环球影城需提前预约
- 地铁覆盖极广，市区景点公共交通优先
- 冬季寒冷干燥，注意保暖与保湿
