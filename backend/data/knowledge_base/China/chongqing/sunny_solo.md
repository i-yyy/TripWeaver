# 城市定位
重庆以独特山城地貌与夜景爆红，抖音、美团热度居高不下，是年轻群体最爱的网红文旅城市。

# 核心亮点
- 魔幻地标：洪崖洞、李子坝轻轨穿楼、长江索道
- 夜景天花板：两江夜游、南山一棵树、龙门浩老街
- 美食顶流：重庆火锅、小面、酸辣粉、江湖菜
- 自然奇观：武隆天坑、仙女山

# 推荐行程
- 1日市区线：解放碑 → 洪崖洞 → 李子坝 → 长江索道
- 1日古镇线：磁器口 → 鹅岭二厂 → 山城步道
- 1日自然线：武隆天坑地缝（需一日往返）

# 适合人群
年轻打卡、摄影爱好者、美食控、情侣、短途旅行

# 出行贴士
- 最佳季节：春秋舒适；夏季偏热，冬季温和
- 地形起伏大，穿舒适走路鞋
- 火锅辣度可选，微辣即可满足多数人
- 夜景建议19:00–21:00拍摄最佳
