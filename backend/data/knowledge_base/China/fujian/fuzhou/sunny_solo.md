# 场景描述

适用于个人独自漫游福州，重点是感受“榕城”的千年闽韵，探访三坊七巷的古厝风情，攀登鼓山俯瞰全城，体验福州温泉的温润，解锁鱼丸、肉燕等地道闽味，在慢节奏中感受古城的烟火气。

# 推荐策略

福州核心景点集中在市区，兼顾人文与休闲，建议安排2天。第一天逛三坊七巷，探访林则徐纪念馆，感受闽派建筑与历史底蕴，傍晚漫步西湖公园；第二天攀登鼓山，感受山林风光，下午体验源脉温泉，舒缓旅途疲惫。市区交通便捷，三坊七巷、西湖公园可步行串联，鼓山有公交直达，温泉场馆可打车前往。

# 可选地点

- 三坊七巷：闽派古厝典范，保留完整古街巷，建议停留2.5小时

- 鼓山：福州地标山体，可登山或乘索道，建议停留2小时

- 西湖公园：福州历史名园，湖光山色秀丽，建议停留1.5小时

- 林则徐纪念馆：纪念民族英雄，免费开放，建议停留1小时

- 源脉温泉：福州老牌温泉，体验温润汤泉，建议停留1.5小时

# 约束与风险

- 三坊七巷周末人流量较大，建议错峰前往，清晨或傍晚最佳

- 鼓山登山台阶较多，徒步需穿舒适鞋子，体力不佳可选择索道

- 温泉体验需提前预约，避免高峰期排队，泡汤后注意保暖

- 福州特色小吃多集中在老城区，可导航前往达明美食街、南后街

# 推荐文案

福州个人漫游建议安排2天，这座被榕树环绕的古城，藏着闽韵与温柔。第一天走进三坊七巷，青石板路蜿蜒，古厝白墙黛瓦，探访林则徐纪念馆，回望民族英雄的传奇岁月，傍晚在南后街尝一碗鱼丸、一颗肉燕，感受地道闽味。第二天登鼓山，俯瞰榕城全景，看闽江蜿蜒流淌，下午泡一场源脉温泉，洗去登山疲惫，感受福州的温润惬意。这里没有喧嚣，只有慢节奏的烟火气，适合一个人慢慢逛，读懂榕城的千年底蕴。
