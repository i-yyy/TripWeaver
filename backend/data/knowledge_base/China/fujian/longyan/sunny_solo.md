# 场景描述

适用于个人独自漫游龙岩，重点是探访古田会议会址感受红色文化，游览永定土楼体验客家建筑智慧，漫步长汀古城感受客家古韵，品尝客家酿豆腐、汀州豆腐干等特色美食，体验龙岩的红色底蕴与客家风情。

# 推荐策略

龙岩核心是红色文化与客家文化，景点分布较广，建议安排2-3天。第一天前往古田会议会址，感受红色历史，下午逛客家土楼民俗文化村；第二天去永定土楼，深度体验土楼建筑，下午前往长汀古城；时间充裕的话，第三天去冠豸山，感受山水风光。各景点间有旅游大巴联动，交通便捷。

# 可选地点

- 古田会议会址：红色革命遗迹，免费开放，建议停留1.5小时

- 永定土楼：世界文化遗产，客家土楼典范，建议安排1天

- 长汀古城：客家首府，保留完整古街，建议停留2小时

- 冠豸山：山水险峻，丹霞地貌，建议安排半天

- 客家土楼民俗文化村：体验客家民俗，建议停留1小时

# 约束与风险

- 古田会议会址需提前预约，参观时需保持安静，尊重历史

- 永定土楼景区较大，各土楼间距离较远，建议乘坐景区观光车

- 长汀古城晚间灯光秀值得一看，建议傍晚前往

- 客家美食口味偏咸香，可尝试酿豆腐、汀州豆腐干、客家米酒

# 推荐文案

龙岩个人漫游建议安排2-3天，这座城市藏着红色的记忆与客家的温情。第一天奔赴古田会议会址，走进革命旧址，回望革命先辈的热血岁月，感受红色文化的深厚底蕴；下午去客家土楼民俗文化村，体验客家民俗，感受客家人民的热情。第二天去永定土楼，看土楼依山而建，感受古人的建筑智慧与客家文化的独特魅力；下午逛长汀古城，走在青石板古街上，尝一碗客家酿豆腐，感受客家古城的烟火气。时间充裕的话，去冠豸山，登山顶俯瞰山水风光，感受自然的灵秀。在这里，红色记忆与客家风情交融，适合一个人慢慢逛，读懂龙岩的独特底蕴。
