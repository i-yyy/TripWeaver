# 场景描述

适用于个人独自漫游莆田，重点是探访湄洲岛妈祖祖庙，感受妈祖文化的深厚底蕴，游览兴化古城的古街古巷，品尝兴化米粉、莆田卤面等特色美食，体验海滨古城的静谧与烟火气。

# 推荐策略

莆田核心是妈祖文化与海滨古韵，建议安排2天。第一天前往湄洲岛，探访妈祖祖庙，感受妈祖文化，漫步海岛沙滩；第二天逛莆田市博物馆了解莆田历史，下午前往广化寺、兴化古城，感受古寺禅意与古城韵味。湄洲岛需乘轮渡前往，市区景点可乘公交或打车直达。

# 可选地点

- 湄洲岛：妈祖文化发源地，海岛风光秀丽，建议安排1天

- 妈祖祖庙：全球妈祖信徒朝圣地，建议停留1.5小时

- 莆田市博物馆：展示莆田历史与妈祖文化，免费开放，建议停留1.5小时

- 广化寺：福建四大古寺之一，禅意浓厚，建议停留1小时

- 兴化古城：保留完整古街，建议停留1.5小时

# 约束与风险

- 湄洲岛轮渡需购票，节假日人流量大，建议错峰前往

- 海岛紫外线较强，需做好防晒措施，沙滩游玩注意安全

- 广化寺参观需遵守寺庙规定，保持安静、衣着整洁

- 莆田卤面、兴化米粉等美食多为本地老店，可导航前往品尝

# 推荐文案

莆田个人漫游建议安排2天，这座海滨古城，藏着妈祖文化的虔诚与兴化古韵的厚重。第一天奔赴湄洲岛，乘轮渡登岛，走进妈祖祖庙，感受千年妈祖文化的魅力，漫步海岛沙滩，看碧海蓝天，吹着海风，享受片刻宁静。第二天先去莆田市博物馆，读懂莆田的历史与文化，下午去广化寺，感受古寺的禅意与静谧，再逛兴化古城，走在青石板古街上，尝一碗兴化米粉、一碗莆田卤面，感受地道兴化风味。在这里，虔诚与烟火相融，适合一个人慢慢逛，感受莆田的独特底蕴。
