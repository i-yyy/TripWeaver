# 场景描述

适用于个人独自漫游泉州，重点是探访海丝文化遗迹，感受开元寺、清净寺的宗教魅力，漫步西街感受古街烟火，品尝面线糊、姜母鸭等地道美食，体验“海上丝绸之路起点”的千年底蕴。

# 推荐策略

泉州核心是海丝古韵与宗教文化，景点集中在市区，建议安排2天。第一天逛西街、开元寺，感受古街与古寺的交融，下午探访清净寺、天后宫，了解多元宗教文化；第二天前往洛阳桥，感受古桥的建筑智慧，下午返回市区深度逛西街，解锁特色美食。市区景点可步行或骑行串联，洛阳桥距离市区约30分钟车程，可乘公交前往。

# 可选地点

- 开元寺：福建最大佛教寺院，古寺底蕴深厚，建议停留1.5小时

- 西街：泉州千年古街，烟火气浓厚，建议停留2小时

- 清净寺：中国现存最古老的伊斯兰教寺院，建议停留1小时

- 天后宫：纪念妈祖，海丝文化遗迹，建议停留40分钟

- 洛阳桥：中国四大古桥之一，建议停留1小时

# 约束与风险

- 西街周末人流量较大，建议错峰前往，清晨可感受宁静古街风貌

- 各宗教场所参观需遵守相关规定，保持安静、衣着整洁

- 洛阳桥桥面较窄，行人较多，需注意安全，避免拥挤

- 泉州美食多为街头巷尾老店，面线糊、姜母鸭、土笋冻值得一试

# 推荐文案

泉州个人漫游建议安排2天，这座海丝古城，藏着千年的繁华与烟火。第一天走进西街，青石板路蜿蜒，古厝与现代小店交融，逛完西街去开元寺，看东西塔矗立千年，感受古寺的静谧与厚重；下午去清净寺，感受伊斯兰教文化的独特魅力，再去天后宫，祭拜妈祖，回望海丝岁月。第二天奔赴洛阳桥，走在千年古桥上，感受古人的建筑智慧，下午返回西街，找一家老店，尝一碗面线糊、一块姜母鸭，感受泉州的烟火气。在这里，多元文化交融，古韵与烟火并存，适合一个人慢慢逛，读懂海丝起点的千年故事。
