# 场景描述

适用于个人独自漫游厦门，重点是登鼓浪屿感受海岛风情，漫步环岛路吹海风，打卡沙坡尾文艺街区，品尝沙茶面、海蛎煎等海鲜美食，在文艺与烟火中感受海滨城市的独特魅力。

# 推荐策略

厦门核心是海岛与文艺氛围，建议安排2-3天。第一天乘轮渡登鼓浪屿，漫步海岛小巷，打卡菽庄花园、日光岩，傍晚返回市区逛曾厝垵；第二天逛沙坡尾文艺街区，漫步环岛路，远眺厦门大学外观；时间充裕的话，第三天可前往南普陀寺，感受佛教文化。鼓浪屿轮渡需提前购票，市区景点可乘公交或打车串联。

# 可选地点

- 鼓浪屿：世界文化遗产，海岛风情浓郁，建议安排1天

- 曾厝垵：海滨美食村落，特色小吃集中，建议停留1.5小时

- 厦门大学（外观）：中国最美校园之一，建议停留30分钟

- 沙坡尾：文艺街区，适合拍照打卡，建议停留1.5小时

- 环岛路：海滨步道，可骑行或漫步，建议停留2小时

# 约束与风险

- 鼓浪屿轮渡需提前1-3天购票，节假日一票难求，务必提前规划

- 鼓浪屿岛内禁止机动车，全程步行，需穿舒适鞋子

- 夏季厦门炎热多雨，需做好防晒、补水与防雨措施

- 曾厝垵、沙坡尾人流量大，注意保管个人财物

# 推荐文案

厦门个人漫游建议安排2-3天，这座海滨小城，藏着浪漫与文艺。第一天乘轮渡登鼓浪屿，走在幽静的海岛小巷，看红瓦绿树映着碧海蓝天，登日光岩俯瞰全岛风光，傍晚尝一碗地道沙茶面，感受海岛烟火。第二天打卡沙坡尾，文艺涂鸦与老建筑碰撞出独特韵味，下午漫步环岛路，吹着海风，看海浪拍岸，远眺厦门大学的红砖绿树。时间充裕的话，去南普陀寺感受宁静，吃一碗素斋。在这里，每一处风景都充满诗意，每一口美食都藏着海滨风味，适合一个人放空自己，邂逅厦门的温柔。
