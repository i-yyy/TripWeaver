# 场景描述

适用于个人独自漫游佛山，重点是探访祖庙感受岭南建筑精髓，参观黄飞鸿纪念馆领略功夫魅力，登西樵山感受禅意与自然，逛清晖园欣赏古典园林，在功夫与烟火间，感受佛山的岭南底蕴。

# 推荐策略

佛山景点以人文与自然结合为主，分布于禅城、顺德、南海等区域，建议安排2-3天。第一天逛祖庙、黄飞鸿纪念馆，感受功夫文化与岭南建筑；下午逛岭南天地，看老建筑焕发新活力。第二天登西樵山，感受禅意与自然风光；下午前往顺德，逛清晖园，领略古典园林之美。第三天品顺德美食，逛逢简水乡，感受水乡风情。市区交通便捷，跨区域可乘坐地铁或公交。

# 可选地点

- 祖庙：岭南建筑瑰宝，佛山文化核心，建议停留1.5小时

- 西樵山：岭南名山，禅意浓厚，自然风光优美，建议安排1天

- 清晖园：广东四大名园之一，古典园林，建议停留1.5小时

- 岭南天地：老建筑改造街区，文艺清新，建议停留2小时

- 黄飞鸿纪念馆：功夫文化地标，展示黄飞鸿生平，建议停留1小时

# 约束与风险

- 西樵山登山路段较长，穿舒适鞋，可乘坐景区观光车节省体力

- 祖庙、清晖园旺季需提前购票，错峰游览体验更佳

- 顺德美食众多，建议适量品尝，避免暴饮暴食

- 岭南天地人流量大，保管好个人财物，夜间游览注意安全

# 推荐文案

佛山个人漫游建议安排2-3天，这座功夫之城，藏着岭南建筑的精巧、功夫文化的底蕴，也藏着让人回味无穷的美食。第一天走进祖庙，红墙黛瓦、雕梁画栋，每一处细节都彰显着岭南建筑的精髓，这里是佛山的文化根脉；参观黄飞鸿纪念馆，看功夫表演，感受洪拳的刚劲有力，追忆一代宗师的传奇一生。下午逛岭南天地，老骑楼改造的街区，文艺清新，既有复古韵味，又有现代气息，适合拍照打卡、休闲漫步。第二天登西樵山，古木参天、禅院林立，感受禅意的宁静，登顶远眺，看群山连绵、风光壮美，下山后逛宝峰寺，静心沉淀。下午前往顺德，走进清晖园，亭台楼阁、小桥流水，一步一景，领略古典园林的雅致与清幽。第三天开启美食之旅，一碗双皮奶，嫩滑香甜；一块盲公饼，酥香可口，还有鱼生、伦教糕等特色美食，解锁顺德“世界美食之都”的魅力；时间充裕逛逢简水乡，小桥流水、古村古宅，感受水乡的宁静与惬意。功夫传承、岭南韵味、美食云集，一个人逛佛山，在人文与自然间，感受这座城市的厚重与灵动。
