# 场景描述
适用于个人独自漫游河源，重点游览万绿湖赏“山中海洋”碧波，打卡恐龙博物馆探秘远古化石，登龟峰塔访宋代古迹，逛太平古街品客家烟火，在湖光山色、历史遗迹与美食间，感受河源的生态之美与人文之韵。
# 推荐策略
河源以生态山水与人文古迹为主，建议安排2-3天。第一天游览万绿湖，乘船逛龙凤岛、水月湾，感受湖水碧绿清澈、岛屿星罗棋布；下午逛恐龙博物馆，观赏全球最多的恐龙蛋化石。第二天登龟峰塔、逛河源博物馆，了解城市历史；漫步太平古街，品客家小吃；晚上看亚洲第一高喷泉。第三天可前往南园古村，探访客家古村落；或泡温泉舒缓身心。市区交通便捷，万绿湖需乘船游览，提前购票。
# 可选地点
- 万绿湖：国家5A景区，华南最大湖泊，湖水碧绿，建议安排1天
- 恐龙博物馆：全球最大恐龙蛋收藏地，化石丰富，建议停留1.5小时
- 龟峰塔：南宋古塔，河源八景之首，历史悠久，建议停留1小时
- 太平古街：骑楼老街，客家文创、小吃汇聚，建议停留1.5小时
- 南园古村：明清客家古村，围龙屋、古祠堂林立，建议停留1.5小时

# 约束与风险
- 万绿湖乘船注意安全，遵守船上规定，爱护生态环境
- 恐龙博物馆、龟峰塔夏季炎热，做好防晒、防暑准备
- 客家美食偏咸香，东江酿豆腐、猪脚粉、老鼠粄为必尝
- 亚洲第一高喷泉每晚20:00-20:30开放，提前占位观赏
# 推荐文案
河源个人漫游建议安排2-3天，这座“珠三角后花园”，藏着万绿湖的碧绿仙境、恐龙的远古秘密与客家的古朴韵味。第一天奔赴万绿湖，这片“山中海洋”湖水清澈见底、碧绿如玉，乘船穿梭于岛屿之间，龙凤岛绿树成荫、水月湾碧波荡漾，湖风拂面、空气清新，仿佛置身世外桃源，看水天一色、白鹭齐飞，治愈所有疲惫。下午打卡恐龙博物馆，这里馆藏上万枚恐龙蛋化石，亲眼目睹“土里藏蛋”的震撼，穿越回远古时代，探秘恐龙的奥秘。第二天登龟峰塔，这座南宋古塔历经千年风雨，砖纹斑驳、古韵悠悠，登顶可俯瞰河源全城风貌；逛河源博物馆，读懂东江流域的历史变迁；漫步太平古街，骑楼林立、灯笼高挂，尝一碗猪脚粉、品一份老鼠粄，感受客家市井的烟火气；晚上前往江边，观赏亚洲第一高喷泉，170米水柱冲天，搭配灯光音乐，震撼又浪漫。第三天探访南园古村，一座座明清客家围龙屋错落有致，古祠堂、青石板路诉说着岁月故事，感受客家古村落的静谧与厚重；或选择泡温泉，温润泉水舒缓旅途疲惫。湖光仙境、远古探秘、客家古韵，一个人逛河源，在清新与静谧间，尽享生态之美、感受人文温度。
