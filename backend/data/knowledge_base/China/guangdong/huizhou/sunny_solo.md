# 场景描述
适用于个人独自漫游惠州，重点漫步惠州西湖感受东坡遗韵，攀登罗浮山问道岭南第一山，奔赴巽寮湾、双月湾享受碧海蓝天，逛水东街品味骑楼烟火，在湖光、山色与大海间，解锁惠州的诗意与浪漫。
# 推荐策略
惠州兼具湖山、人文与滨海风光，建议安排2-3天。第一天逛惠州西湖，骑行苏堤、打卡泗洲塔，感受“苎萝西子”的清幽；下午逛水东街、东坡祠，品味人文底蕴。第二天登罗浮山，探访冲虚古观、登高飞云顶，感受道家仙风。第三天前往巽寮湾或双月湾，踏浪玩沙、品尝海鲜，享受滨海惬意。市区交通便捷，滨海景点建议打车或拼车前往。
# 可选地点
- 惠州西湖：国家5A景区，苏堤春晓、泗洲塔相映成趣，建议停留2小时
- 罗浮山：岭南第一山，道教第七洞天，飞瀑流泉，建议安排1天
- 巽寮湾：“广东马尔代夫”，碧海银滩，适合休闲度假，建议停留1天
- 双月湾：双湾三景奇观，海景壮阔，适合看日出日落，建议停留1天
- 水东街：宋代古街，骑楼林立，夜景璀璨，建议停留1.5小时

# 约束与风险
- 罗浮山登山路段较长，穿舒适防滑鞋，可乘索道节省体力
- 西湖夏季多雨、滨海夏季紫外线强，做好防晒与防雨准备
- 巽寮湾、双月湾旺季人流量大，提前预订住宿与景区项目
- 惠州美食偏鲜香，客家菜、海鲜可按需选择，肠胃敏感者适量食用
# 推荐文案
惠州个人漫游建议安排2-3天，这座“岭南名郡”，藏着西湖的诗意、罗浮的仙风与大海的浪漫。第一天漫步惠州西湖，苏堤垂柳、九曲通幽，泗洲塔倒映湖面，仿佛穿越回东坡先生笔下的“一更山吐月，玉塔卧微澜”，骑行环湖，清风拂面，惬意十足。下午逛水东街，骑楼斑驳、灯火璀璨，尝一份阿嫲叫、品一碗横沥汤粉，感受市井烟火；探访东坡祠，追寻文豪足迹，读懂惠州的人文底蕴。第二天奔赴罗浮山，这座“岭南第一山”云雾缭绕、古观清幽，冲虚古观香烟袅袅，朱明洞飞瀑潺潺，登顶飞云顶，俯瞰云海翻涌、群山连绵，感受道家仙风与自然壮美。第三天踏上海边之旅，巽寮湾的碧海银滩细腻柔软，踩沙踏浪、扬帆出海，治愈所有疲惫；或去双月湾，看双湾相依、日出东方，壮美绝伦，傍晚在海鲜街大快朵颐，现捞现烹的海产鲜掉眉毛。湖山诗意、山海浪漫，一个人逛惠州，步步皆景、处处有情。
