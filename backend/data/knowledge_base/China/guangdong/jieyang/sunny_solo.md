# 场景描述
适用于个人独自漫游揭阳，重点漫步揭阳古城感受岭南水城韵味，打卡进贤门地标，登黄岐山俯瞰全城，逛阳美翡翠城感受玉都魅力，品潮汕美食，在水城、古建与翡翠间，感受揭阳的灵动与厚重。
# 推荐策略
揭阳兼具古城、山水与翡翠文化，建议安排2-3天。第一天逛揭阳古城、进贤门，感受水城古韵；下午逛中山路、打铜街，品潮汕小吃。第二天登黄岐山，登山祈福、俯瞰全城；下午逛阳美翡翠城，了解翡翠文化、赏美玉。第三天前往望天湖，享受生态休闲、花海景观；时间充裕逛市区，感受城市氛围。市区交通便捷，景点间可公交或打车，望天湖建议拼车前往。
# 可选地点
- 揭阳古城：岭南水城，水系环绕、古宅林立，建议停留2小时
- 进贤门：揭阳地标，古城门楼，可登楼观景，建议停留1小时
- 黄岐山：城市名山，森林茂密、古迹众多，建议停留2小时
- 阳美翡翠城：“亚洲玉都”，翡翠交易、鉴赏中心，建议停留2小时
- 望天湖：生态度假区，花海、湖景、休闲项目，建议停留1天

# 约束与风险
- 古城水系较多，注意安全，避免靠近水边危险区域
- 黄岐山登山穿舒适鞋，量力而行，夏季做好防晒
- 阳美翡翠城消费较高，了解行情后再购买，谨防假货
- 潮汕美食偏鲜，普宁豆干、揭西擂茶、粿条汤为必尝
# 推荐文案
揭阳个人漫游建议安排2-3天，这座“岭南水城”，水网纵横、古韵悠悠，更有“亚洲玉都”的璀璨与潮汕美食的鲜香。第一天漫游揭阳古城，这里是“水上莲花”的核心，水系环绕古城，古桥、古宅、青石板路相映成趣，漫步街巷，感受水城的灵动与古韵。打卡进贤门，这座揭阳地标性古城楼，飞檐翘角、气势恢宏，登楼俯瞰，古城与新城尽收眼底，感受城市的古今交融。下午逛中山路、打铜街，老骑楼、老作坊林立，尝一份外酥里嫩的普宁豆干、喝一碗鲜香的粿条汤，感受市井烟火。第二天攀登黄岐山，山上绿树成荫、空气清新，岐山塔、侣云寺等古迹点缀其间，登山祈福、俯瞰全城，风光尽收眼底。下午奔赴阳美翡翠城，这座“亚洲玉都”玉石琳琅满目、璀璨夺目，逛翡翠市场、了解玉雕工艺，感受玉文化的博大精深，即便不买，赏美玉也赏心悦目。第三天前往望天湖生态度假区，花海烂漫、湖光秀美，可漫步赏花、体验休闲项目，享受自然生态的惬意与放松。水城灵动、玉都璀璨、美食鲜香，一个人逛揭阳，在古韵与现代间，感受这座城市的独特魅力。
