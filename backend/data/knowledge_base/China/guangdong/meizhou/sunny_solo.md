# 场景描述
适用于个人独自漫游梅州，重点探访客家博物馆读懂客都底蕴，漫步雁南飞茶田感受绿意茶香，逛松口古镇追溯侨乡乡愁，攀登五指石观赏丹霞奇观，在古建、茶田与美食间，感受世界客都的质朴与厚重。
# 推荐策略
梅州以客家文化与自然景观为主，景点分布较散，建议安排2-3天。第一天逛中国客家博物馆、南华又庐，了解客家历史与围龙屋建筑；下午逛松口古镇，感受南洋侨韵。第二天前往雁南飞茶田，漫步茶田、体验采茶、品客家茗茶；下午攀登五指石，走玻璃栈道、赏丹霞风光。第三天可逛叶剑英故居、黄遵宪故居，感受人文风骨；时间充裕泡客家温泉，舒缓身心。市区至景区建议打车或拼车，交通便捷。
# 可选地点
- 中国客家博物馆：全面展示客家文化，免费参观（需预约），建议停留1.5小时
- 雁南飞茶田：5A景区，千亩茶田翠绿，可体验采茶，建议停留2小时
- 松口古镇：南洋侨乡古镇，骑楼古街、火船码头，建议停留2小时
- 五指石：丹霞地貌+玻璃栈道，俯瞰粤闽赣三省，建议停留2.5小时
- 南华又庐：“九厅十八井”围龙屋，建筑精美，建议停留1小时

# 约束与风险
- 五指石登山与玻璃栈道需量力而行，穿舒适防滑鞋
- 松口古镇、茶田春季绿意盎然、气候舒适，适合游览
- 客家美食偏咸香，盐焗鸡、酿豆腐、腌面为必尝，肠胃敏感者适量食用
- 景区特产价格偏高，市区梅江二路选购伴手礼更实惠
# 推荐文案
梅州个人漫游建议安排2-3天，这座“世界客都”，藏着客家先民的智慧、侨乡的乡愁与舌尖的乡愁。第一天走进中国客家博物馆，从围龙屋模型到客家民俗展品，读懂客家人的迁徙史与文化根脉；探访南华又庐，这座百年围龙屋“九厅十八井”，雕梁画栋、布局精巧，感受客家建筑的鬼斧神工。下午漫步松口古镇，南洋骑楼连绵、古码头斑驳，这里是客家人下南洋的起点，每一块石板都藏着乡愁，夕阳下的古镇古韵悠悠，拍照超出片。第二天奔赴雁南飞茶田，漫山翠绿、茶香四溢，漫步茶田栈道，亲手采摘茶叶，品一杯清香的客家绿茶，感受田园的宁静与惬意。下午攀登五指石，丹霞赤壁巍峨壮观，悬空玻璃栈道惊险刺激，登顶远眺，三省风光尽收眼底，壮美震撼。第三天探访名人故居，叶剑英故居的质朴、黄遵宪故居的文雅，感受客家文人的风骨；傍晚品一桌客家盛宴，盐焗鸡皮脆肉嫩、酿豆腐鲜香滑嫩、腌面搭配三及第汤，地道风味暖胃又暖心。客韵悠悠、茶香袅袅、烟火浓浓，一个人逛梅州，在历史与自然间，寻根乡愁、治愈心灵。
