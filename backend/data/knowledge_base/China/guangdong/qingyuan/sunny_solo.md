# 场景描述
适用于个人独自漫游清远，重点体验黄腾峡、古龙峡漂流的刺激清凉，探秘连州地下河的溶洞仙境，攀登金子山赏高山云海，逛牛鱼嘴享森林绿意，在山水、漂流与溶洞间，感受清远的自然活力与生态之美。
# 推荐策略
清远以漂流、山水与溶洞为主，景点分散，建议安排2-3天。第一天体验漂流，选黄腾峡或古龙峡，感受峡谷激流、清凉刺激；下午逛牛鱼嘴，呼吸森林氧吧。第二天前往连州，游览连州地下河，乘船观赏溶洞奇观；下午逛连州古城，感受人文底蕴。第三天攀登金子山，登高望远、看云海日出；时间充裕泡温泉，舒缓身心。漂流景区建议报一日游或打车前往，连州景点较远，建议拼车或自驾。
# 可选地点
- 黄腾峡：“漂流之王”，峡谷惊险刺激，水质清澈，建议停留半天
- 古龙峡：网红漂流，玻璃桥、峡谷瀑布，玩法多样，建议停留半天
- 连州地下河：国家5A景区，地下溶洞+暗河，“神秘瑰丽”，建议停留2小时
- 金子山：粤湘交界名山，云海、日出、冰挂（冬季），建议安排1天
- 牛鱼嘴：原始森林，瀑布、溪谷、玻璃吊桥，建议停留2小时

# 约束与风险
- 漂流适合夏季，穿速干衣、带换洗衣物，做好防晒、防水措施
- 漂流时抓好扶手、避免站立，遵守景区安全指引，保管好随身物品
- 连州地下河洞内气温较低，带薄外套，乘船坐稳扶好
- 金子山登山路段陡峭，穿防滑鞋，量力而行，冬季注意防寒
# 推荐文案
清远个人漫游建议安排2-3天，这座“中国漂流之乡”，藏着刺激的峡谷漂流、神秘的溶洞仙境与壮美的高山风光。第一天开启清凉漂流之旅，选择黄腾峡，峡谷两岸绿树成荫，河道激流险滩不断，乘皮艇顺流而下，穿梭于峡谷之间，浪花飞溅、尖叫不断，全程清凉刺激，甩掉所有烦恼；或打卡古龙峡，漂流搭配玻璃桥、瀑布景观，玩法更丰富。下午逛牛鱼嘴原始森林，溪谷潺潺、瀑布飞流，走玻璃吊桥俯瞰森林绿意，呼吸高浓度负离子，身心舒畅。第二天奔赴连州，探秘连州地下河，乘船穿行于地下溶洞，钟乳石形态各异、晶莹剔透，暗河曲折幽深、灯光梦幻，仿佛闯入地下仙境，惊叹大自然的神奇造物。下午逛连州古城，青石板路、古巷民居，感受千年古城的人文烟火，品连州菜心、东陂水角等地道美食。第三天攀登金子山，这座“岭南第一险峰”山势陡峭、风景壮美，登顶俯瞰，云海翻涌、群山连绵，晴天看日出、冬季赏冰挂，震撼至极。漂流刺激、溶洞神秘、高山壮美，一个人逛清远，在自然山水间，尽情释放活力、享受清新。
