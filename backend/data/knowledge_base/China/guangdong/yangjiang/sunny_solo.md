# 场景描述
适用于个人独自漫游阳江，重点登海陵岛逛大角湾、十里银滩，踏浪玩沙、看日出日落，探访马尾岛赏日落秘境，前往阳春看溶洞奇观，在碧海银滩、山海溶洞与海鲜美食间，感受阳江的滨海活力与自然壮美。
# 推荐策略
阳江核心景点为海陵岛与阳春溶洞，建议安排2-3天。第一天登海陵岛，逛大角湾、十里银滩，享受沙滩与海水；傍晚去马尾岛看绝美日落。第二天海陵岛自由活动，体验海上项目或逛闸坡渔港买海鲜；下午返程市区。第三天前往阳春，游览凌霄岩，观赏喀斯特溶洞奇观；时间充裕逛阳江市区，品特色美食。市区至海陵岛有直达公交，阳春景点建议打车前往。
# 可选地点
- 海陵岛：中国十大最美海岛，碧海银滩，建议安排1-2天
- 大角湾：海陵岛核心沙滩，沙细水清，游乐项目多，建议停留2小时
- 十里银滩：绵长银滩、风光壮阔，适合漫步看海，建议停留2小时
- 马尾岛：海陵岛日落秘境，植被茂密、海景柔美，建议停留1.5小时
- 凌霄岩：阳春喀斯特溶洞，钟乳石壮观，“南国第一洞府”，建议停留2小时

# 约束与风险
- 海陵岛夏季炎热、紫外线强，做好防晒、补水，避开正午高温
- 海上项目选择正规商家，穿戴救生设备，注意安全
- 闸坡渔港买海鲜可现场加工，价格实惠，避免被宰
- 阳春溶洞内地面湿滑，穿防滑鞋，照明不佳处小心行走
# 推荐文案
阳江个人漫游建议安排2-3天，这座“山海之城”，藏着中国最美的海岛银滩与雄奇的溶洞奇观。第一天奔赴海陵岛，这座“南方北戴河”碧海环绕、银滩绵延，大角湾的沙滩细腻柔软，踩沙踏浪、体验摩托艇、香蕉船，尽情释放活力；漫步十里银滩，海岸线一望无际，海风轻拂、涛声阵阵，看海浪层层涌来，壮阔又治愈。傍晚前往马尾岛，这里是海陵岛最佳日落观赏点，夕阳将天空与海面染成金红色，岛屿、渔船、晚霞相映成画，浪漫到极致。第二天继续海岛慢生活，或在沙滩躺卧发呆、听海看云，或逛闸坡渔港，看渔船归港、海鲜满仓，亲手挑选鲜活海产，现场加工品尝，鲜掉眉毛；下午返程市区，感受滨海城市的烟火气。第三天前往阳春，探秘凌霄岩，这座“南国第一洞府”内钟乳石千姿百态、石笋石柱林立，灯光映照下五彩斑斓，仿佛走进地下仙境，惊叹大自然的鬼斧神工。海岛浪漫、溶洞雄奇、海鲜鲜美，一个人逛阳江，在山海之间，尽享自由与惬意。
