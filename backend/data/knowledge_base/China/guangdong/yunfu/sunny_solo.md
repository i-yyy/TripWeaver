# 场景描述
适用于个人独自漫游云浮，重点探访国恩寺感受禅宗祖庭禅意，逛石材博览中心领略石都魅力，游览蟠龙洞观赏溶洞奇观，泡温泉舒缓身心，在禅意、奇石与山水间，感受云浮的宁静与厚重。
# 推荐策略
云浮以禅宗文化、石材与自然景观为主，建议安排2-3天。第一天参观国恩寺、六祖故居，感受禅宗文化；下午逛新兴县城，品当地美食。第二天游览蟠龙洞，观赏“宝石花”溶洞奇观；下午逛石材博览中心，了解石都文化。第三天攀登天露山，看高山草甸、壮美风光；时间充裕泡金水台温泉，舒缓身心。市区至新兴、天露山建议打车或拼车，交通便捷。
# 可选地点
- 国恩寺：禅宗六祖慧能故居，千年古刹，禅意浓厚，建议停留1.5小时
- 蟠龙洞：省级景区，喀斯特溶洞，“宝石花”奇观，建议停留2小时
- 石材博览中心：“中国石都”展示中心，奇石荟萃，建议停留1小时
- 天露山：粤西名山，高山草甸、云海壮美，建议安排1天
- 金水台温泉：温泉度假区，舒缓身心，建议停留2小时

# 约束与风险
- 国恩寺参观遵守宗教礼仪，保持安静、文明礼佛
- 蟠龙洞内地面湿滑，穿防滑鞋，注意安全，洞内灯光较暗
- 天露山登山路段较长，穿舒适防滑鞋，量力而行，带足水与干粮
- 温泉泡汤避开高峰期，泡后注意保暖，及时补水
# 推荐文案
云浮个人漫游建议安排2-3天，这座“中国石都、禅宗故里”，藏着禅宗的宁静、奇石的瑰丽与山水的壮美。第一天奔赴新兴，探访国恩寺，这座禅宗六祖慧能的故居与弘法地，千年古刹古木参天、香火鼎盛，晨钟暮鼓、禅意悠悠，漫步寺院，静心感受禅宗文化的博大精深，沉淀内心、忘却烦恼。下午逛新兴县城，品当地特色美食，裹蒸粽、勒竹水糕、山坑螺，鲜香入味，感受市井烟火。第二天游览蟠龙洞，这座喀斯特溶洞内奇石林立、钟乳石千姿百态，更有罕见的“宝石花”奇观晶莹剔透、璀璨夺目，灯光映照下宛如地下仙境，惊叹大自然的鬼斧神工。下午逛云浮石材博览中心，这里是“中国石都”的窗口，各类石材、石雕、奇石琳琅满目，从建筑石材到工艺精品，领略石都文化的魅力与厚重。第三天攀登天露山，这座粤西第一高峰山势巍峨，高山草甸连绵成片，登顶远眺，云海翻涌、群山连绵，风光壮美震撼，感受自然的辽阔与壮美；下山后泡金水台温泉，温润泉水舒缓旅途疲惫，放松身心。禅意悠悠、奇石瑰丽、山水壮美，一个人逛云浮，在宁静与壮阔间，治愈心灵、感受美好。
