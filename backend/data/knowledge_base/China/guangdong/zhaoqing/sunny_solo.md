# 场景描述

适用于个人独自漫游肇庆，重点是游览七星岩感受喀斯特山水的诗意，登鼎湖山呼吸森林氧吧，探访端砚文化村领略砚都魅力，漫步宋城墙感受古城底蕴，在山水与文化间，感受肇庆的诗意与厚重。

# 推荐策略

肇庆景点以山水与文化结合为主，建议安排2-3天。第一天游览七星岩，乘游船逛星湖，感受喀斯特山水的诗意；下午逛宋城墙，感受古城历史。第二天登鼎湖山，感受森林氧吧与瀑布风光；下午探访端砚文化村，了解端砚制作工艺。第三天可前往阅江楼，感受历史文化；时间充裕可逛肇庆古城墙周边，感受市井烟火。市区交通便捷，景点间可乘坐公交或打车。

# 可选地点

- 七星岩：喀斯特山水景观，“岭南第一奇观”，建议安排1天

- 鼎湖山：岭南四大名山之一，森林氧吧，建议停留2.5小时

- 端砚文化村：中国砚都核心，端砚制作基地，建议停留1.5小时

- 宋城墙：肇庆古城墙，历史悠久，建议停留1小时

- 星湖：七星岩周边湖泊，游船观光，建议停留1.5小时

# 约束与风险

- 鼎湖山登山路段多，穿舒适防滑鞋，量力而行

- 七星岩游船旺季需提前购票，错峰游览体验更佳

- 端砚文化村部分作坊不对外开放，尊重当地规定

- 肇庆夏季炎热多雨，出行需做好防晒、备齐雨具

# 推荐文案

肇庆个人漫游建议安排2-3天，这座“中国砚都”，藏着喀斯特山水的诗意，也藏着端砚文化的厚重。第一天走进七星岩，喀斯特峰林矗立在星湖之上，湖水清澈、峰峦叠翠，乘游船穿梭其间，仿佛走进一幅山水画卷，“借得西湖水一圜，更移阳朔七堆山”，便是对七星岩最美的写照。下午漫步宋城墙，斑驳的城墙见证着肇庆的千年历史，登上城墙，俯瞰古城风貌，感受岁月的沧桑。第二天登鼎湖山，古木参天、瀑布飞流，这里是中国第一个自然保护区，森林覆盖率极高，呼吸着新鲜的空气，仿佛置身天然氧吧，下山后逛庆云寺，感受禅意的宁静。下午探访端砚文化村，走进作坊，看工匠们精心制作端砚，感受端砚文化的博大精深，可亲手体验简单的砚台制作，感受传统文化的魅力。第三天前往阅江楼，感受历史文化的厚重；时间充裕逛古城墙周边，品尝裹蒸粽等当地美食，感受市井烟火气。山水诗意、砚韵悠长，一个人逛肇庆，在自然与文化间，沉淀自我、感受美好。
