# 场景描述
适用于个人独自漫游中山，重点探访孙中山故居了解伟人生平，逛孙文西路感受骑楼古韵，游詹园品味岭南园林，逛岭南水乡体验田园闲适，在人文、园林与水乡间，感受中山的温情与底蕴。
# 推荐策略
中山以人文古迹、园林与水乡为主，建议安排2-3天。第一天参观孙中山故居、孙中山纪念馆，读懂伟人历史；下午逛孙文西路步行街，感受骑楼风情、品中山美食。第二天游览詹园，观赏岭南最大私家庭园；下午逛长江水库，享受自然湖景。第三天前往岭南水乡，体验疍家风情、田园风光；时间充裕逛中山市区，感受宜居氛围。市区公交便捷，水乡景点建议打车或拼车前往。
# 可选地点
- 孙中山故居：伟人故里，全国文保单位，免费参观，建议停留1.5小时
- 孙文西路：百年骑楼老街，商业繁华、古韵悠悠，建议停留2小时
- 詹园：岭南最大私家庭园，亭台水榭、精致典雅，建议停留2小时
- 长江水库：城市生态湖，山清水秀、休闲惬意，建议停留1.5小时
- 岭南水乡：疍家风情、田园风光，体验水乡生活，建议停留2小时

# 约束与风险
- 孙中山故居参观遵守规定，保持安静、文明游览
- 孙文西路人流量大，保管好个人财物，注意安全
- 詹园、水乡夏季多雨，备好雨具，做好防晒
- 中山美食偏清淡，石岐乳鸽、小榄炸鱼球、沙溪牛肉为必尝
# 推荐文案
中山个人漫游建议安排2-3天，这座伟人故里，既有深厚的人文底蕴，也有雅致的岭南园林与闲适的水乡风情。第一天走进孙中山故居，翠亨村的青砖瓦房、农家院落，保留着伟人童年生活的模样，参观纪念馆，通过史料、文物读懂孙中山先生的革命生涯与家国情怀，感受历史的厚重。下午逛孙文西路，百年骑楼连绵成片，南洋风格建筑古韵悠悠，商铺林立、美食飘香，尝一只皮脆肉嫩的石岐乳鸽、品一份鲜香的沙溪牛肉，在骑楼光影下，感受中山的市井烟火。第二天游览詹园，这座岭南最大私家庭园，亭台楼阁错落有致、假山池沼相映成趣，雕梁画栋、古树参天，每一处都尽显岭南园林的精致典雅，漫步其间，静心感受中式美学的韵味。下午逛长江水库，湖水碧绿、群山环抱，微风拂面、鸟语花香，享受城市中的自然静谧。第三天奔赴岭南水乡，河道纵横、小桥流水，疍家渔船停泊岸边，体验水乡捕鱼、采摘蔬果，品尝农家菜，感受田园牧歌般的闲适生活。伟人风骨、园林雅致、水乡闲适，一个人逛中山，在人文与自然间，感受这座宜居城市的温情与美好。
