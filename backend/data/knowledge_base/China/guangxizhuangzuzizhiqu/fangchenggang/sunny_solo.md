# 场景描述

适用于个人独自漫游防城港，重点是漫步白浪滩、金滩，感受黑沙白浪奇观；逛东兴口岸，体验中越边关风情；探访簕山古渔村，感受渔家烟火，在山海与边关间，领略独特风光。

# 推荐策略

防城港景点沿北部湾分布，建议2天。第一天逛白浪滩、怪石滩，玩滨海项目；下午前往簕山古渔村，感受古村静谧。第二天去万尾金滩，看金滩日落；下午逛东兴口岸，逛越南风情街。各景点间有公交、打车可达，金滩、白浪滩可租电动车骑行。

# 可选地点

- 白浪滩：黑沙白浪，滩平浪缓，建议停留2小时

- 万尾金滩：沙色金黄，日落绝美，京族聚居地，建议停留2小时

- 东兴口岸：中越边境，异国风情，建议停留1.5小时

- 簕山古渔村：明清古渔村，渔家风情，建议停留1.5小时

- 怪石滩：海蚀地貌，奇石林立，建议停留1小时

# 约束与风险

- 滨海地区紫外线强，做好防晒、防风

- 东兴口岸人流量大，保管好个人财物

- 古渔村潮汐变化大，赶海需提前查询时间

- 海鲜、越南小吃为特色，按需选择

# 推荐文案

防城港个人漫游建议安排2天，这座边陲港城，藏着山海与边关的双重浪漫。第一天漫步白浪滩，黑沙细腻、白浪翻滚，踩沙踏浪超惬意。逛怪石滩，奇石林立、海浪拍岸，拍照超出片。下午去簕山古渔村，百年古树、古朴渔家，感受宁静的渔村生活。第二天去万尾金滩，看夕阳把沙滩染成金色，听京族民歌悠扬。下午逛东兴口岸，站在国境线，感受中越风情交融，买越南特产、吃越南美食。山海相依、边关风情，一个人逛防城港，小众又治愈。
