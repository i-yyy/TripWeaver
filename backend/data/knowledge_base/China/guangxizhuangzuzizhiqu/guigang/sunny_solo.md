# 场景描述

适用于个人独自漫游贵港，重点是登桂平西山感受佛教禅意，逛北帝山看丹霞奇景，游东湖公园赏荷花，在荷香与禅意间，感受贵港的宁静与壮美。

# 推荐策略

贵港景点分市区与周边，建议2天。第一天登桂平西山，拜佛、赏景、品西山茶；下午逛东湖公园，夏季赏荷花。第二天去北帝山，看丹霞地貌、走玻璃栈道；时间充裕可去平天山。桂平西山、北帝山距市区约1小时车程，公交、旅游大巴可达。

# 可选地点

- 桂平西山：佛教名山，“南天第一秀山”，建议停留2.5小时

- 北帝山：“广西小张家界”，丹霞地貌，建议停留2小时

- 东湖公园：千年古湖，夏季荷花满塘，建议停留1.5小时

- 龙潭国家森林公园：原始森林，瀑布溪流，建议安排半天

- 平天山：高山草甸，露营观星，建议安排半天

# 约束与风险

- 北帝山登山台阶多，部分路段险峻，穿舒适鞋

- 桂平西山寺庙多，遵守宗教礼仪，保持安静

- 荷花最佳观赏季为6-8月，错峰游览更佳

- 贵港美食偏清淡，豆腐酿、猪脚粉值得一试

# 推荐文案

贵港个人漫游建议安排2天，这座“荷城”，藏着禅意与壮美。第一天登桂平西山，古木参天、寺庙林立，品一杯西山茶，感受禅意静心。下午逛东湖公园，夏日荷花盛开，接天莲叶无穷碧，超治愈。第二天去北帝山，丹霞奇峰、云雾缭绕，走玻璃栈道，惊险又刺激。看群山连绵、风光壮美，心旷神怡。荷香悠悠、禅意绵绵、奇峰壮美，一个人逛贵港，宁静又放松。
