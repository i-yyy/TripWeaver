# 场景描述

适用于个人独自漫游桂林，重点是乘竹筏游漓江，打卡20元人民币背景图，逛阳朔西街，漫步遇龙河，攀登龙脊梯田，在山水田园间，感受如诗如画的喀斯特风光。

# 推荐策略

桂林山水核心为漓江与阳朔，建议3天。第一天桂林市区：象鼻山、两江四湖，感受城景交融。第二天漓江竹筏漂流至阳朔，逛西街、看印象刘三姐。第三天遇龙河步道漫步或骑行；时间充裕可前往龙脊梯田，感受田园壮阔。漓江竹筏需提前预约，龙脊梯田距市区约2小时车程。

# 可选地点

- 漓江：山水精华段，20元背景实景，建议安排1天

- 象鼻山：桂林城徽，水月洞奇景，建议停留1小时

- 阳朔西街：千年古街，夜生活丰富，建议停留2小时

- 遇龙河：“小漓江”，竹筏漂流、骑行，建议停留2小时

- 龙脊梯田：千层梯田，四季皆景，建议安排1天

# 约束与风险

- 漓江竹筏旺季（4-10月）需提前3天预约

- 龙脊梯田登山路段多，穿舒适鞋，雨季湿滑注意安全

- 阳朔西街夜晚人流量大，保管好个人财物

- 桂林米粉、啤酒鱼为必尝美食，按需选择辣度

# 推荐文案

桂林个人漫游建议安排3天，这里的山水是中国最美的诗意画卷。第一天在桂林市区，看象鼻山形似巨象饮水，漫步两江四湖，感受城在景中、景在城中。第二天乘竹筏游漓江，看两岸奇峰林立、碧水悠悠，打卡20元人民币背景图，抵达阳朔逛西街，感受古街的热闹与文艺。第三天骑行遇龙河，看田园倒影如画；时间充裕就去龙脊梯田，千层梯田如链似带，壮阔震撼。山水相依、田园静谧，一个人逛桂林，处处是诗，步步是画。
