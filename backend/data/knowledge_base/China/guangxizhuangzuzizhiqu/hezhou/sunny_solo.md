# 场景描述

适用于个人独自漫游贺州，重点是漫步黄姚古镇，感受千年古韵；登姑婆山，呼吸森林氧吧；逛玉石林，看喀斯特石林奇观，在古镇与自然间，感受长寿之乡的宁静美好。

# 推荐策略

贺州核心为黄姚古镇与姑婆山，建议2天。第一天逛黄姚古镇，走石板街、看古桥古巷，感受古镇静谧。第二天登姑婆山，逛森林瀑布、茶园；下午逛玉石林，看石林奇观。黄姚古镇距市区约1小时车程，姑婆山约30分钟，公交、旅游大巴可达。

# 可选地点

- 黄姚古镇：千年古镇，石板街、古桥、古巷，建议安排1天

- 姑婆山：森林氧吧，瀑布、茶园，建议停留2.5小时

- 玉石林：喀斯特石林，白色奇石，建议停留1.5小时

- 十八水：瀑布群，避暑胜地，建议停留1.5小时

- 紫云洞：喀斯特溶洞，钟乳石奇观，建议停留1小时

# 约束与风险

- 黄姚古镇昼夜温差大，备薄外套

- 姑婆山登山台阶多，穿舒适鞋，注意休息

- 古镇内石板路较滑，雨天注意安全

- 贺州美食偏清淡，黄姚豆腐酿、瓜花酿值得一试

# 推荐文案

贺州个人漫游建议安排2天，这座长寿之乡，藏着千年古镇与自然秘境。第一天走进黄姚古镇，青石板路、青砖黛瓦、古桥流水，漫步其中，时光都慢下来。看灯笼摇曳、炊烟袅袅，感受千年古韵。第二天登姑婆山，森林茂密、瀑布飞溅，呼吸新鲜空气，超治愈。下午逛玉石林，白色石林千姿百态，仿佛走进童话世界。古镇静谧、自然清新，一个人逛贺州，慢享时光静好。
