# 场景描述

适用于个人独自漫游来宾，重点是登金秀圣堂山，看云海奇峰；逛大岭瑶寨，感受瑶族风情；泡象州温泉，舒缓身心，在瑶乡与山水间，感受桂中的灵秀与惬意。

# 推荐策略

来宾景点以金秀与象州为核心，建议2天。第一天登圣堂山，看云海、丹霞奇峰；下午逛大岭瑶寨，体验瑶族文化。第二天泡象州温泉，休闲放松；下午逛古沙沟。金秀距市区约2小时车程，象州约1小时，旅游大巴可达。

# 可选地点

- 金秀圣堂山：瑶族圣山，云海、丹霞奇峰，建议安排1天

- 象州温泉：优质温泉，休闲疗养，建议停留2小时

- 金秀大岭瑶寨：瑶族古寨，民俗风情，建议停留1.5小时

- 古沙沟：森林峡谷，生态休闲，建议停留1.5小时

- 百崖大峡谷：峡谷瀑布，避暑胜地，建议停留2小时

# 约束与风险

- 圣堂山登山台阶陡峭、海拔高，注意高反，量力而行

- 瑶寨参观需尊重瑶族习俗，礼仪得当

- 温泉泡汤需提前预约，避免高峰期，泡后保暖

- 来宾美食偏鲜香，瑶家腊肉、象州米粉值得一试

# 推荐文案

来宾个人漫游建议安排2天，这座桂中城市，藏着瑶乡圣山与温泉惬意。第一天登金秀圣堂山，石阶蜿蜒、奇峰林立，云雾缭绕时，仿佛置身仙境。看丹霞红岩、云海翻涌，壮美震撼。下午逛大岭瑶寨，走进瑶族古寨，看瑶寨建筑、听瑶族民歌、体验瑶族习俗，感受浓郁的民族风情。第二天泡象州温泉，温润泉水舒缓旅途疲惫，放松身心。下午逛古沙沟，森林茂密、溪流清澈，惬意休闲。圣山壮美、瑶情浓郁、温泉治愈，一个人逛来宾，自在又舒适。
