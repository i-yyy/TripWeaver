# 场景描述

适用于个人独自漫游柳州，重点是探访工业博物馆了解城市历史，登马鞍山俯瞰全城夜景，在龙潭公园感受喀斯特山水，逛窑埠古镇、品正宗螺蛳粉，体验工业与山水交融的独特风情。

# 推荐策略

柳州市区与周边景点结合，建议2-3天。第一天逛龙潭公园，感受山水风光；下午参观柳州工业博物馆，傍晚登马鞍山看夜景。第二天逛窑埠古镇，体验古风与现代融合；时间充裕可第三天前往三江程阳八寨，感受侗族风雨桥与鼓楼文化。市区交通便捷，程阳八寨需1.5小时车程。

# 可选地点

- 龙潭公园：喀斯特山水园林，免费4A景区，建议停留2小时

- 马鞍山：柳州制高点，夜景灯光秀震撼，建议停留1.5小时

- 柳州工业博物馆：工业历史缩影，老机械展陈，建议停留1.5小时

- 窑埠古镇：古镇夜景、美食集中地，建议停留2小时

- 程阳八寨：侗族古寨，风雨桥、鼓楼群，建议安排1天

# 约束与风险

- 马鞍山登山台阶较陡，注意安全，体力不足可乘缆车

- 螺蛳粉口味较重，可选择少辣、少酸

- 程阳八寨昼夜温差大，需备薄外套

- 窑埠古镇夜景最佳，建议17:00后前往

# 推荐文案

柳州个人漫游建议安排2-3天，这座工业之城藏着山水柔情与美食香气。第一天走进龙潭公园，奇峰怪石、碧水潺潺，仿佛置身山水画卷。下午参观工业博物馆，看老火车、旧机械，读懂柳州的工业传奇。傍晚登马鞍山，俯瞰万家灯火，柳江如带，夜景绝美。第二天逛窑埠古镇，红灯笼、青石板，吃一碗正宗螺蛳粉，鲜辣酸爽回味无穷。时间充裕就去程阳八寨，看百年风雨桥、鼓楼，听侗族大歌。工业硬朗与山水温柔相融，一个人逛柳州，每一步都有惊喜。
