# 场景描述

适用于个人独自漫游南宁，重点是感受“半城绿树半城楼”的绿城风貌，探访三街两巷的老城记忆，体验广西民族博物馆的壮乡风情，在老友粉的酸辣鲜香中，感受南宁的包容与活力。

# 推荐策略

南宁景点集中于市区，建议安排2天。第一天登青秀山，俯瞰全城绿意，游览兰园与桃花岛；下午逛广西民族博物馆，了解铜鼓、壮锦文化。第二天漫步三街两巷，逛城隍庙、品老友粉；下午游南湖公园，傍晚可去南宁之夜感受网红街区氛围。市区地铁、公交便捷，景点间可骑行串联。

# 可选地点

- 青秀山：城市绿肺，龙象塔俯瞰邕城，建议停留2.5小时

- 三街两巷：明清骑楼老街，老城烟火核心，建议停留2小时

- 广西民族博物馆：壮族文化宝库，铜鼓、干栏建筑展，建议停留1.5小时

- 南湖公园：城市内湖，夜景灯光秀美，建议停留1小时

- 南宁方特东盟神画：东盟主题乐园，一日玩遍十国，建议安排半天

# 约束与风险

- 南宁夏季湿热，出行需做好防晒、补水

- 青秀山面积大，建议乘坐景区观光车，节省体力

- 三街两巷傍晚人流量大，错峰游览体验更佳

- 老友粉口味酸辣，初次尝试可选择微辣

# 推荐文案

南宁个人漫游建议安排2天，这座被称为“绿城”的城市，四季常绿、满城花香。第一天登青秀山，走在茂密的林间步道，看邕江绕城而过，在兰园静赏幽兰芬芳。下午去广西民族博物馆，触摸千年铜鼓的纹路，感受壮乡文化的厚重。第二天漫步三街两巷，青石板路、青砖黛瓦，一碗热气腾腾的老友粉，酸辣开胃，唤醒老南宁的记忆。傍晚在南湖边散步，看灯光倒映湖面。这里没有喧嚣，只有绿意与烟火，适合一个人慢慢感受绿城的温柔与活力。
