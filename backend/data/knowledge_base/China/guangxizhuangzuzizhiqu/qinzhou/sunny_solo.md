# 场景描述

适用于个人独自漫游钦州，重点是去三娘湾邂逅中华白海豚，逛八寨沟避暑玩水，探访刘永福故居感受英雄历史，漫步钦州老街品烟火气，在海豚与古郡间，感受钦州的独特魅力。

# 推荐策略

钦州景点分滨海与山水，建议2天。第一天去三娘湾，乘船寻白海豚，逛沙滩；下午逛刘永福故居。第二天逛八寨沟，避暑玩水；下午漫步钦州老街，品尝美食。三娘湾距市区约1小时车程，八寨沟约40分钟，公交、打车可达。

# 可选地点

- 三娘湾：中华白海豚栖息地，观豚胜地，建议停留2.5小时

- 八寨沟：峡谷溪流，避暑玩水，建议停留2小时

- 刘永福故居（三宣堂）：民族英雄故居，清代建筑，建议停留1小时

- 钦州老街：骑楼老街，美食集中，建议停留1.5小时

- 仙岛公园：城市公园，远眺钦州港，建议停留1小时

# 约束与风险

- 白海豚出没无绝对规律，最佳观豚季为4-11月

- 八寨沟内湿滑，穿防滑鞋，注意安全

- 三娘湾乘船需穿救生衣，听从工作人员指挥

- 猪脚粉、瓜皮醋为必尝美食，口味偏鲜

# 推荐文案

钦州个人漫游建议安排2天，这座海豚之城、古郡之地，藏着惊喜与温柔。第一天奔赴三娘湾，乘船出海，期待邂逅粉色的中华白海豚，看它们跃出海面，浪漫又治愈。沙滩漫步、吹海风，感受滨海惬意。下午参观刘永福故居，走进英雄故居，感受爱国情怀。第二天逛八寨沟，峡谷幽深、溪水清澈，玩水避暑，超舒服。下午漫步钦州老街，骑楼斑驳、小吃飘香，吃一碗猪脚粉，软糯鲜香。古郡底蕴、海豚浪漫，一个人逛钦州，小众又美好。
