# 场景描述

适用于个人独自漫游梧州，重点是漫步骑楼城感受百年商埠繁华，探访龙母庙了解岭南祈福文化，登白云山俯瞰全城，品尝纸包鸡、龟苓膏，在粤语古韵中，感受岭南古城的深厚底蕴。

# 推荐策略

梧州景点集中于老城区，建议2天。第一天逛骑楼城、龙母庙，感受岭南建筑与文化；下午登白云山，俯瞰西江与桂江汇流。第二天参观梧州博物馆，了解城市历史；下午逛苍海湖，感受生态休闲。市区景点可步行、骑行串联，交通便捷。

# 可选地点

- 骑楼城：岭南骑楼建筑群，百年商埠，建议停留2小时

- 龙母庙：岭南最大龙母庙，祈福圣地，建议停留1.5小时

- 白云山公园：城市制高点，两江汇流全景，建议停留1.5小时

- 梧州博物馆：历史文物展陈，免费开放，建议停留1小时

- 苍海湖：生态湖泊，休闲漫步，建议停留1小时

# 约束与风险

- 骑楼城夏季炎热，建议清晨或傍晚游览

- 龙母庙参观需遵守宗教礼仪，保持安静

- 梧州美食偏甜，纸包鸡、冰泉豆浆值得一试

- 白云山登山步道平缓，适合休闲徒步

# 推荐文案

梧州个人漫游建议安排2天，这座岭南古城，是粤语发源地、百年商埠。第一天漫步骑楼城，骑楼连绵、古韵悠悠，仿佛穿越回百年前的繁华商埠。走进龙母庙，香火鼎盛，感受岭南独特的祈福文化。下午登白云山，看西江、桂江汇流，全城风光尽收眼底。第二天参观梧州博物馆，读懂古城千年历史；下午逛苍海湖，微风拂面、惬意休闲。尝一口纸包鸡，鲜香酥脆；品一碗龟苓膏，清凉回甘。岭南风情、古韵悠长，一个人逛梧州，慢品时光静好。
