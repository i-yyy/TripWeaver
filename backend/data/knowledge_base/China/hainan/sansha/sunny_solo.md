# 场景描述
适合追求极致纯净海景的旅行者，乘船前往西沙海域，探访人迹罕至的小岛，看玻璃般透明的海水、洁白沙洲与原始海洋生态。

# 推荐策略
三沙旅行需通过正规旅游邮轮渠道，行程多为4天3晚。主要登全富岛、银屿、鸭公岛等，以观光、生态体验、爱国主义教育为主，不可自由离队。

# 可选地点
- 西沙群岛：中国最美海域之一，海水层次分明
- 全富岛：无人沙洲，纯白沙滩，拍照极美
- 银屿：小型海岛，可浅滩漫步
- 七连屿：岛礁群，生态原始

# 约束与风险
- 必须通过官方邮轮，不可私自登岛
- 受天气、海况影响大，晕船者提前准备药物
- 岛上设施简单，物资有限，做好准备
- 严格保护海洋生态，禁止带走贝壳珊瑚

# 推荐文案
三沙是中国版图最南端的蓝色秘境。这里的海是渐变的蓝，沙滩白得耀眼，人少、安静、纯净得不像人间。乘船破浪而来，站在沙洲上眺望无边大海，能真切感受到祖国海疆的壮阔与美丽。一次三沙行，是独行者最特别的海洋记忆。
