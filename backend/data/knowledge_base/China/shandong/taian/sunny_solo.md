# 场景描述

适用于个人独自漫游泰安，重点是攀登泰山、观赏日出，体验“五岳独尊”的壮丽。

# 推荐策略

登山有两条经典路线：夜爬红门线看日出，或日间天外村乘车+缆车轻松游。建议安排2天，第一天逛岱庙，傍晚开始登山或入住山顶；第二天看完日出后下山。岱庙是泰山脚下必游景点，古代帝王封禅之地。

# 可选地点

- 泰山：五岳独尊，夜爬看日出或日间登山，建议安排一整天

- 岱庙：泰山脚下，古代帝王封禅之地，建议停留1.5-2小时

- 泰山地下大裂谷：溶洞奇观，漂流体验，建议停留2小时

# 约束与风险

- 夜爬泰山体力消耗大，需备好手电、厚外套

- 山顶气温比山下低10℃以上，看日出需租大衣

- 节假日人流量巨大，索道排队可能2小时以上

- 建议提前预订山顶住宿（价格较高）或选择夜爬

- “特种兵式”一日往返较累，建议安排2天

# 推荐文案

泰山个人漫游建议安排2天。如果体力好、想看日出，就选夜爬路线：傍晚逛完岱庙，晚上从红门出发，爬四五个小时到南天门，租件大衣等日出。当太阳从云海中跃出的那一刻，所有的疲惫都值得。如果想轻松点，白天从天外村坐车上山再换缆车，山顶逛逛就走。不管哪种方式，岱庙都值得先去，那是泰山文化的起点。下山后可以泡泡温泉，给双腿放个假。
