# 场景描述

适用于个人独自在烟台开展Citywalk，核心是通过精选的官方路线，串联山海景观、复古街区、网红地标与本地美食，行程轻松不赶，2天即可解锁烟台精华，兼顾打卡与体验感。

# 推荐策略

第一天从官方6条Citywalk路线中选择1-2条，优先推荐人文山海线或滨海休闲线，串联烟台山、朝阳街、所城里或海昌渔人码头等点位，傍晚前往美食街品尝本地特色。第二天前往养马岛，体验“果冻海”、赶海等项目，春季可搭配龙湖樱花大道，乘坐17路双层环海公交，低成本看遍海岸线。

# 可选地点

- 人文山海线（烟台山→朝阳街→所城里）：烟台山赏花、百年冬青长廊，朝阳街摩登复古，所城里600年历史+非遗手作，建议停留3-4小时

- 滨海休闲线（海昌渔人码头→虞美人广场→黄海游乐城）：“小欧洲”建筑、宫崎骏同款“入海轨道”，可在躔度咖啡看海，建议停留2-3小时

- 网红打卡线（时光塔→金沙滩“巨鲸雕塑”→后沙广场）：新晋网红地标，巨鲸雕塑震撼，适合拍照，建议停留1.5小时

- 养马岛：“果冻海”、赶海、骑马换装，烟台版“苍洱大道”，建议安排一整天

- 龙湖樱花大道：春季限定，近3000株海岸樱花，建议春季上午停留1-2小时

- 烟大小吃街、上夼西路美食街：本地美食集中，可品尝新鲜生蚝等特色小吃，建议傍晚停留1-2小时

# 约束与风险

- 烟台青旅选择较少，以酒店为主，建议提前预订，避免旺季无房

- 养马岛距离市区有一定距离，建议安排一整天，避免往返仓促

- 龙湖樱花大道为春季限定，其他季节无樱花景观，需提前规划出行时间

- 17路双层环海公交高峰时段可能拥挤，建议错峰乘坐

# 推荐文案

烟台2天个人Citywalk行程，精选官方路线解锁山海与烟火。第一天选人文山海线或滨海休闲线，逛烟台山、朝阳街，吃特色小吃；第二天去养马岛看“果冻海”、赶海，春季可赏海岸樱花。坐2元双层环海公交看海，轻松解锁烟台的仙境海岸与鲁菜风味。
