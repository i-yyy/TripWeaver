# 城市定位
成都稳居旅游热度前列，以“巴适”生活方式、熊猫与美食出圈，是短途度假与深度休闲的顶流城市。

# 核心亮点
- 国宝IP：大熊猫繁育研究基地
- 美食天堂：火锅、串串、川菜、小吃遍地
- 城市休闲：人民公园喝茶、掏耳朵、慢逛老街
- 世界遗产：都江堰、青城山、三星堆

# 推荐行程
- 1日市区线：熊猫基地 → 宽窄巷子 → 锦里 → 春熙路
- 1日世遗线：都江堰 → 青城山
- 1日古蜀线：三星堆博物馆 → 市区美食
- 1日摆烂线：人民公园 → 望平街 → 建设路小吃

# 适合人群
美食爱好者、休闲度假、亲子家庭、年轻打卡群体

# 出行贴士
- 最佳季节：3–6月、9–11月气候舒适
- 熊猫基地建议早上去，熊猫更活跃
- 火锅微辣起步，按需选择辣度
- 周边景点建议一日往返，市区节奏放慢
