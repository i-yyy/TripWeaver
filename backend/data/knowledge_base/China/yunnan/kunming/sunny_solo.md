# 城市定位
昆明位列旅游百强地市第一，气候优势全国罕见，是云南旅游集散中心与避寒度假胜地。

# 核心亮点
- 世界奇观：石林世界地质公园
- 城市生态：滇池、翠湖、红嘴鸥（冬季）
- 民族风情：云南民族村、多民族文化体验
- 鲜花城市：斗南花市，亚洲最大鲜花市场

# 推荐行程
- 1日自然线：石林一日游
- 1日城市线：翠湖 → 云南陆军讲武堂 → 滇池海埂大坝
- 1日风情线：民族村 → 斗南花市

# 适合人群
避寒度假、中老年康养、家庭出行、摄影、云南中转

# 出行贴士
- 最佳季节：全年适宜，11–3月温暖舒适
- 紫外线较强，注意防晒
- 石林距离市区较远，建议一日往返
- 消费整体亲民，性价比突出
